Data Import

How import works: Each row creates a new record. Import does not update or merge existing records.

  • All prices and monetary values must be in VND — even if you are currently viewing in USD.
  • For Products and Customers, include the code column to preserve existing codes. Leave it blank to auto-generate.
  • For Categories, duplicate names are silently skipped (safe to re-import).
  • For Inventory, the product must already exist. Quantity must be greater than 0.
  • Orders, Returns, and Refunds cannot be imported — they involve FIFO stock, state machines, and accounting rules that cannot be safely replayed from CSV.

Import Categories

Create categories in bulk. Rows whose name already exists are skipped — safe to re-import.

Expected CSV Format

name,description
Electronics,Electronic devices and accessories
Clothing,Fashion and apparel
Furniture,Home and office furniture

Column description is optional.

Import Products

Import products. Categories that don't exist yet are created automatically. All prices in VND.

Expected CSV Format

product_code,name,category,sale_price,cost_price,barcode,min_stock_level
EL0001,Laptop,Electronics,12000000,8000000,SKU001,5
EL0002,Mouse,Electronics,150000,100000,SKU002,20
,Desk,Furniture,2000000,1200000,SKU003,2

product_code is optional — leave blank to auto-generate from category (e.g. EL0001).
barcode and min_stock_level are optional. category is optional.

Import Customers

Import customer records. Include customer_code to preserve existing codes, or leave blank to auto-generate (KH######).

Expected CSV Format

customer_code,name,email,phone,address,region
KH000001,Nguyen Van A,nguyenvana@email.com,0901234567,123 Le Loi HCM,South
,Jane Smith,jane@email.com,0987654321,456 Oak Ave,North
KH000003,Bob Johnson,bob@email.com,0912345678,789 Pine Rd,Central

customer_code is optional. If provided and already in use, that row will fail (no update).
email, phone, address, region are all optional.

Import Inventory

Add intake lots to existing products. The product must already exist. Quantity must be greater than 0. All costs in VND (or USD if currency is set to USD).

Expected CSV Format

product_code,quantity,cost_price,shipping_cost,currency,intake_date,notes
EL0001,100,8000000,500000,VND,2026-04-01,Initial stock
EL0002,50,15,2,USD,2026-04-02,Imported from US supplier
EL0003,20,100000,,,2026-04-03,No shipping cost

Use product_code or product_name to identify the product.
shipping_cost, currency (VND or USD), and notes are optional.
intake_date format: YYYY-MM-DD. Leave blank to use today's date.
